# MagnaVille — versão HTML, CSS e JavaScript

Esta versão foi emancipada do Lovable/React/TypeScript.

## Estrutura
- `index.html` — estrutura e textos do site
- `css/style.css` — aparência
- `js/script.js` — dados e interações
- `imagens/` — imagens do site
- `favicon.ico` — ícone

## Como abrir
Basta abrir `index.html` no navegador. Não precisa de Node, npm, Vite, React ou TypeScript.

## Onde editar
- Textos e estrutura: `index.html`
- Cores, tamanhos e layout: `css/style.css`
- Serviços, obras, profissionaiss e contatos: `js/script.js`
